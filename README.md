# Paradise Nursery

**Project name:** Paradise Nursery – Online Plant Shop Shopping Cart Application

Paradise Nursery is a React + Redux Toolkit shopping cart app for an online houseplant shop.

## Features
- Landing page with company name, background image, and a "Get Started" button
- About Us section describing the company
- Product listing with 18 houseplants in 3 categories (thumbnail, name, price)
- "Add to Cart" buttons that disable once a plant is added
- Navbar (Home, Plants, Cart) with a live cart item count
- Shopping cart page: per-plant subtotal, total amount, increase/decrease quantity, delete, Checkout ("Coming Soon") and Continue Shopping

## Tech stack
React 18, Redux Toolkit, React-Redux, Vite

## Run locally
```bash
npm install
npm run dev
```
Then open the URL shown in the terminal (usually http://localhost:5173).
